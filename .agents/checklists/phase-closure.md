# Checklist de clôture de phase

Avant de clôturer une phase, vérifier :

## Étapes

- [ ] Toutes les étapes de la phase sont terminées
- [ ] Chaque étape a un audit avec verdict acceptable
- [ ] Aucune étape en état `BLOCKED` non résolu

## Livrables

- [ ] Tous les livrables de la phase sont produits
- [ ] Les livrables sont dans les emplacements documentés

## Qualité

- [ ] Tests exécutés et résultats documentés
- [ ] Revues indépendantes effectuées (si applicable)
- [ ] Non-conformités corrigées ou tracées comme réserves acceptées

## Documentation

- [ ] `PLANS.md` mis à jour (états des tâches)
- [ ] `PROJECT_STATE.md` mis à jour
- [ ] `HANDOFF.md` mis à jour
- [ ] `HUMAN_GATES.md` mis à jour
- [ ] ADR créés pour les décisions structurantes
- [ ] `RISKS.md` mis à jour si nouveaux risques
- [ ] `TECHNICAL_DEBT.md` mis à jour si nouvelle dette

## Audit final

- [ ] Audit final de phase réalisé
- [ ] Verdict : `CONFORME` ou `CONFORME AVEC RÉSERVES`
- [ ] Rapport de clôture produit

## Arrêt

- [ ] Statut passé à `PHASE_CLÔTURÉE_EN_ATTENTE_DU_GO_HUMAIN`
- [ ] Prochaine phase identifiée mais NON lancée
- [ ] Aucune action sur la phase suivante exécutée
