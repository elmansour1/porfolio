# Données réelles à préparer

## Statut

Créé en Phase 1 — Cadrage produit.

## Objectif

Identifier les contenus que le propriétaire doit fournir progressivement pour éviter un portfolio visuellement réussi mais peu crédible.

## Profil

- Photo professionnelle utilisable publiquement.
- Titre professionnel court.
- Résumé en français.
- Résumé en anglais.
- Biographie courte.
- Biographie détaillée.
- Localisation.
- Disponibilité professionnelle.
- Adresse e-mail professionnelle.
- Téléphone facultatif.
- CV PDF.
- Liens LinkedIn, GitHub et autres plateformes.

## Expériences

Pour chaque expérience :

- entreprise ou description anonymisée ;
- poste ;
- type de contrat ;
- lieu ;
- dates ;
- missions ;
- réalisations ;
- technologies ;
- éléments confidentiels à exclure.

## Projets

Pour chaque projet publiable :

- titre ;
- résumé ;
- contexte ;
- problème ;
- solution ;
- rôle ;
- responsabilités ;
- technologies ;
- fonctionnalités ;
- défis ;
- résultats réels disponibles ;
- captures ou visuels autorisés ;
- liens publics ;
- contraintes de confidentialité.

## Compétences

- Catégories.
- Compétences réelles.
- Description courte par compétence.
- Niveau qualitatif si utile, sans pourcentage arbitraire.

## Services

- Services réellement proposés.
- Bénéfices pour le client ou recruteur.
- Livrables possibles.
- Types de clients ou missions visés.

## Landing publique

Avant mise en ligne, vérifier et publier :

- profil principal complet en français et anglais ;
- titre professionnel réel ;
- résumé court crédible ;
- disponibilité réelle ou masquée ;
- statistiques uniquement si vérifiables ;
- compétences principales publiées ;
- expériences/formations/certifications publiables ;
- projets mis en avant avec visuels autorisés ;
- services réellement proposés ;
- méthode de travail publiée ;
- coordonnées ou liens de contact autorisés.

## Identité

- Monogramme ou logo éventuel.
- Préférences de ton rédactionnel.
- Références visuelles acceptées.
- Contraintes d'image personnelle.

## Témoignages

Ne préparer que des témoignages réels et autorisés. Si aucun témoignage réel n'est disponible, la section reste masquée.
