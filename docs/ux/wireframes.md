# Wireframes textuels

## Statut

Validé en Phase 3 — Conception UX/UI du portfolio.

Ces wireframes décrivent la structure, la hiérarchie et les parcours. Ils ne remplacent pas une maquette visuelle ou une inspection navigateur.

## W-001 — Landing publique desktop

```text
[Header: monogramme/nom | Accueil | À propos | Compétences | Expériences | Projets | Services | Contact | FR/EN | CTA Contact]

[Hero pleine largeur]
Nom + titre professionnel
Proposition de valeur courte
CTA principal: Voir mes projets
CTA secondaire: Me contacter / Télécharger CV si disponible
Visuel professionnel réel ou placeholder explicitement non publié
Technologies principales en ligne

[Crédibilité factuelle]
Années/projets/domaines seulement si valeurs réelles

[À propos]
Résumé éditorial + points de différenciation concrets

[Compétences]
Catégories: Backend, Frontend, Database, DevOps, Conception
Chaque compétence: nom + description courte + niveau qualitatif facultatif

[Projets mis en avant]
Cartes sobres: image, titre, résumé, rôle, technologies, confidentialité si applicable

[Expériences]
Timeline ou liste verticale structurée

[Services]
Offres activables avec bénéfices et livrables

[Méthode]
Comprendre -> Cadrer -> Concevoir -> Développer -> Tester -> Livrer -> Accompagner

[Contact]
Formulaire + coordonnées + réseaux

[Footer]
Résumé, navigation, légal, réseaux, copyright
```

## Réserves

- Les dimensions, couleurs et composants exacts devront être inspectés sur maquette ou interface.
- Les textes finaux FR/EN ne sont pas créés pendant cette phase.
- Aucune donnée fictive ne doit être publiée.
