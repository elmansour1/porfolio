# Checklist UX/UI SaaS premium

| Critère | Résultat | Commentaire |
|---------|----------|-------------|
| Hiérarchie visuelle | PASS/FAIL | Action principale identifiable, titres structurés |
| Mise en page | PASS/FAIL | Grille cohérente, alignements, espacements |
| Design system | PASS/FAIL | Couleurs, typo, boutons, champs, rayons, ombres cohérents |
| États d'interface | PASS/FAIL | Chargement, vide, erreur, succès, accès refusé, etc. |
| Responsive adaptatif | PASS/FAIL | Pas seulement empiler — adapter priorité, navigation, densité |
| Cohérence métier | PASS/FAIL | Workflow respecté, actions autorisées, statuts expliqués |
| PrimeNG/Tailwind/SCSS | PASS/FAIL | Pas de duplication, pas de surcharges globales |
| Interactions | PASS/FAIL | Retours après opérations, pas de parcours sans issue |
| Accessibilité | PASS/FAIL | Sémantique, labels, clavier, contrastes |
| Inspection visuelle | PASS/FAIL/NOT EXECUTED | Rendu réel vérifié si possible |

Références qualitatives (sans reproduction) : Stripe, Linear, Notion, Framer, Revolut.

Ne pas déclarer SaaS premium sans contrôle visuel suffisant.
