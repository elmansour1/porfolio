# Definition of Done

Une tâche est `DONE` lorsque tous les critères suivants sont satisfaits :

- [ ] Comportement implémenté conformément aux critères d'acceptation
- [ ] Critères d'acceptation vérifiés (pas supposés)
- [ ] Code de qualité senior (backend et/ou frontend selon le périmètre)
- [ ] Architecture respectée
- [ ] Build exécuté avec succès (lorsque possible)
- [ ] Tests exécutés avec résultats documentés
- [ ] Erreurs gérées correctement
- [ ] Sécurité vérifiée dans le périmètre
- [ ] Performance évaluée (proportionnée au besoin)
- [ ] UX/UI validée (lorsque applicable)
- [ ] Accessibilité validée (lorsque applicable)
- [ ] Absence de modifications hors périmètre
- [ ] Documentation mise à jour
- [ ] Audit réalisé avec verdict acceptable
- [ ] État mis à jour dans `PLANS.md`
- [ ] `HANDOFF.md` prêt

Verdicts d'audit acceptables : `CONFORME` ou `CONFORME AVEC RÉSERVES ACCEPTÉES ET TRACÉES`.
