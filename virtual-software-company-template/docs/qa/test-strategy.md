## Niveaux de test

| Niveau | Périmètre | Outil | Responsable |
|--------|-----------|-------|-------------|
| Unitaire | Règles métier, composants, services | À définir | QA + agents concernés |
| Intégration | Persistance, API, transactions | À définir | QA + Backend |
| API | Contrats, codes HTTP, erreurs | À définir | QA + Backend |
| Frontend | Composants, formulaires, permissions | À définir | QA + Frontend |
| E2E | Parcours critiques | À définir | QA |
| Sécurité | Auth, permissions, injection | À définir | Security + QA |

## Principes

- Les tests vérifient des comportements, pas des détails internes fragiles
- Pas de déclaration de tests réussis sans exécution réelle
- Tests de régression obligatoires pour les corrections de bug
