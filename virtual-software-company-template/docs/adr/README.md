# Architecture Decision Records (ADR)

## Usage

Chaque décision structurante est documentée ici sous forme d'ADR.

## Quand créer un ADR

- Architecture et découpage
- Choix technologique structurant
- Authentification et autorisation
- Modèle de données majeur
- Migration significative
- Intégration externe
- Infrastructure
- Choix frontend transversal (SSR/CSR, state management)
- Sécurité structurante

## Quand ne PAS créer un ADR

- Correction locale
- Renommage mineur
- Détail sans impact durable
- Préférence personnelle

## Format

Utiliser le template : `.agents/templates/adr-template.md`
